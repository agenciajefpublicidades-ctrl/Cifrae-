# Cifraê V5 Real

Aplicação web de análise musical local.

## Recursos
- Upload de áudio e vídeo compatível com o navegador
- Reprodução local
- Estimativa de BPM
- Estimativa de tonalidade com confiança
- Progressão provável de acordes
- Processamento no navegador, sem envio do áudio neste protótipo

## Publicação
Projeto preparado para hospedagem estática na Netlify.
